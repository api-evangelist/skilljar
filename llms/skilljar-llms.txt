# Skilljar

> Skilljar is a customer education / external LMS platform (part of Gainsight) for creating, publishing, and measuring training programs, academies, and certification. Its REST API exposes courses, lessons, learning paths, domains, users, enrollments, quizzes, purchases, instructor-led/VILT training, and real-time webhooks.

The Skilljar API is a large OpenAPI 3.0.3 surface: 160 paths, 340 operations, 420 schemas. Base URL `https://api.skilljar.com/v1/`. v1 authenticates with an Organization API key over HTTP Basic (key as username, empty password); a v2 OAuth 2.0 surface (authorization_code + refresh_token, PKCE S256, ~89 scopes) is advertised via RFC 8414 metadata. Pagination is page-number (`page`/`page_size`, `count`/`next`/`previous`/`results`).
